# Тестовое задание. Курс JAVA. Утилита фильтрации содержимого файлов

## Основной функционал
Утилита предназначена для фильтрации и сортировки содержимого файлов.
При запуске в командной строке передается список файлов, каждый из которых содержит целые числа, вещественные числа и строки, разделенные переводом строки.
Утилита последовательно читает строки из файлов в порядке их указания в командной строке и распределяет данные по разным файлам в зависимости от их типа (целые числа, вещественные числа и строки).
По умолчанию результирующие файлы перезаписываются, но с помощью аргументов командной строки можно настроить различные опции работы утилиты.

## Поддерживаемые флаги
| Флаг | Функционал                                                                                     | Примечание                                                                                                                                                                                                                       |
|-----|------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| -o  | Задает путь для результатов                                                                    | Если указанная директория не существует, она будет автоматически создана                                                                                                                                                         |
| -p  | Задает префикс имен выходных файлов                                                            |                                                                                                                                                                                                                                  |
| -a  | Задать режим добавления в существующие файлы  | По умолчанию файлы результатов перезаписываются                                                                                                                                                                                  |
| -s  | Вывод краткой статистики в консоль                                                             | Краткая статистика содержит количество элементов                                                                                                                                                                                 |
| -f  | Вывод полной статистики в консоль                                                              | Полная статистика для чисел содержит количество элементов, минимальное и максимальное значения, сумму и среднее. Полная статистика для строк, помимо их количества, содержит также размер самой короткой строки и самой длинной. |

## Сборка и запуск проекта
- В корневой директории проекта выполнить команду

```
mvn clean package 
```
- Для запуска приложения выполняем 
```
java -jar target/cft_test_v3-1.0-SNAPSHOT.jar [options] [input_files]
```
